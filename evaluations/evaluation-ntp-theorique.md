# Evaluation NTP Théorique

## Critères

| Critère              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Forme                | <p>Indiviuelle, saus aucune aide<br>Formulaire Office 365</p>                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Pondération          | 50% de la note NTP                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Temps à disposition  | 45 min                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Compétences évaluées | <ul><li>Mettre en évidence et détailler les raisons du NTP.</li><li>Comprendre et expliquer les concepts de base du <a href="https://fr.wikipedia.org/wiki/Network_Time_Protocol">protocole NTP </a>(architecture, acheminement de l'heure)</li><li>Connaître le contenu des messages (OT, RT, TT)</li><li>Savoir lire et interpréter les résultats des différentes commandes du NTP (entraînées en pratique)</li></ul><p>Note : aucun calcul ni aucune formule ne sera demandés.</p> |
